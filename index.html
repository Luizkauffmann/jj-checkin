⚙ One-time Setup — Get your free API Key

  1. Go to console.cloud.google.com → sign in with your Google account
  2. Create a new project (name it anything, e.g. dojo-tracker)
  3. Go to APIs & Services → Library → search Google Sheets API → Enable it
  4. Go to APIs & Services → Credentials → click Create Credentials → API Key
  5. Click Edit API Key → under Application restrictions → select Websites → add https://YOUR-USERNAME.github.io/*
  6. Under API restrictions → select Restrict key → choose Google Sheets API only → Save
  7. Copy the key → paste it in the yellow box above → click Save Key
  8. The key is stored only in your browser. Visitors to the public page cannot save anything.
Your API key lives only in your browser · Never uploaded to GitHub · Public visitors are read-only
